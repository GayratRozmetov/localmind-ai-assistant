## Live Demo

**[Open LocalMind AI Business Assistant](https://localmind-ai-assistant.cloudy-beech-0660.chatgpt.site)**

A free, private AI assistant that runs a real language model entirely inside the browser — without API keys, subscriptions or per-message charges.

## Features

- Real on-device language model powered by WebLLM
- Customer reply generator
- E-commerce product copy assistant
- Social media caption writer
- Professional business email creator
- Turkish, English and Russian translation mode
- Private browser-based conversation history
- Responsive commercial-grade interface
- No backend and no API key required

## Privacy

Prompts and generated content remain on the user's device. The application does not send conversations to a remote AI API.

## Requirements

- Latest Google Chrome or Microsoft Edge
- WebGPU-compatible computer
- Internet connection for the first model download
- Several hundred MB of available browser storage

After the first model download, there is no message-based usage fee.

## Technology

- Next.js
- React
- TypeScript
- WebLLM
- WebGPU
- Local Storage

## Local Development

```bash
npm install
npm run dev
```

## Limitations

LocalMind uses a compact model designed to run on consumer hardware. It is private and free to use, but response quality and speed may be lower than cloud-based commercial AI services.
